Configure one proxy for outbound sandbox connections with [`WithProxy`](#m-withproxy). Proxy protocols are mutually exclusive; currently only SOCKS5 is supported.

See [Outbound proxy](/networking/outbound-proxy) for runtime behavior, security considerations, and current transport limitations.

## Typical flow

```go
sb, err := m.CreateSandbox(ctx, "worker",
    m.WithImage("python"),
    m.WithProxy(m.SOCKS5Proxy("127.0.0.1:1080")),
)
```
